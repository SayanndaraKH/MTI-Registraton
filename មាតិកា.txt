១. មុខងារសំខាន់ៗដែលគួរមាន (Core Features)
1. Core Features
កាតាឡុកវគ្គសិក្សា (Course Catalog): កន្លែងបង្ហាញវគ្គខ្លីៗ និងកម្មវិធីដែលអ្នកលក់ (ឈ្មោះវគ្គ, អត្ថប្រយោជន៍, តម្លៃ)។
 Course Catalog:  A place to display short courses and programs that you sell (course name, benefits, price).

ប្រព័ន្ធចុះឈ្មោះ (Registration System): ទាមទារឲ្យសិស្សបញ្ចូលព័ត៌មាន (ឈ្មោះ, លេខទូរស័ព្ទ, ឈ្មោះគណនី Telegram)។
 Registration System:  requires students to enter information (name, phone number, Telegram account name).

ការទូទាត់ប្រាក់តាម KHQR (Dynamic KHQR Payment): ប្រព័ន្ធគួរតែបង្កើត KHQR Code ស្វ័យប្រវត្តិដែលមានភ្ជាប់តម្លៃ និងលេខកូដសម្គាល់ប្រតិបត្តិការ (Invoice ID) ដើម្បីងាយស្រួលផ្ទៀងផ្ទាត់។
 Dynamic KHQR Payment:  The system should automatically generate a KHQR Code with a value and Invoice ID for easy verification.

ការផ្ទៀងផ្ទាត់ការបង់ប្រាក់ (Payment Verification): អ្នកអាចភ្ជាប់ API របស់ធនាគារ (ដូចជា ABA PayWay ឬ Bakong) ដើម្បីឲ្យប្រព័ន្ធដឹងថាលុយចូលភ្លាមៗដោយស្វ័យប្រវត្តិ។
 Payment Verification:  You can connect to the bank's API (such as ABA PayWay or Bakong) to let the system know that the money is deposited automatically.

ប្រព័ន្ធគ្រប់គ្រងតំណភ្ជាប់ (Invite Link Manager): បង្កើត Link ចូលក្រុម Telegram ប្រភេទ "One-time use" (ប្រើបានតែម្តង) ដើម្បីការពារកុំឲ្យសិស្សយក Link នោះទៅចែករំលែកបន្តឲ្យអ្នកផ្សេង។
 Invite Link Manager:  Create a link to the Telegram group "One-time use" to prevent students from sharing the link with others.

ផ្ទាំងគ្រប់គ្រងសម្រាប់អ្នក (Admin Dashboard): សម្រាប់មើលទិន្នន័យសិស្ស ចំណូល និងគ្រប់គ្រងវគ្គសិក្សា។
 Admin Dashboard:  View student earnings and course management data.

Web Framework: ប្រើ FastAPI ឬ Flask ព្រោះវាលឿន និងងាយស្រួលក្នុងការធ្វើការជាមួយ Webhooks របស់ Telegram និងធនាគារ។
 Web Framework:  Use  FastAPI  or  Flask  because it is fast and easy to work with Telegram and Bank Webhooks.

 Telegram Bot Integration:  Use the aiogram or python-telegram-bot library to receive notifications and interactive messages.

Database: ប្រើ SQLite (សម្រាប់ចាប់ផ្តើម) ឬ PostgreSQL ដើម្បីរក្សាទុកទិន្នន័យសិស្ស និងប្រវត្តិបង់ប្រាក់។
 Database:  Use  SQLite  (for starters) or  PostgreSQL  to store student data and payment history.

Payment (KHQR): ប្រើបណ្ណាល័យ khqr (Python package មួយចំនួនមានស្រាប់លើ GitHub) ដើម្បី Generate QR code មុននឹងភ្ជាប់ API ធនាគារពិតប្រាកដ។
 Payment (KHQR):  Use the khqr library (some Python packages are already available on GitHub) to generate QR code before connecting to the actual banking API.
